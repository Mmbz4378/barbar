# فونت‌های رشن

پیش‌فرض این نسخه IRANYekanX است. چهار وزن Regular (۴۰۰)، Medium (۵۰۰)، DemiBold (۶۰۰) و Bold (۷۰۰) از فایل‌های موجود کاربر در Downloads/Webfonts/woff2 اضافه شده‌اند. فونت از خود سایت بارگیری می‌شود و به سرویس بیرونی وابسته نیست.

تعریف وزن‌ها و font-display: swap در public/assets/css/reshen.css است. برای بازگشت به وزیرمتن، UI_FONT=vazirmatn را در تنظیمات محیط قرار دهید. چیدمان‌ها باید data-font را از تنظیم مشترک بخوانند. وزیرمتن و فایل مجوز OFL آن نیز موجود هستند.

فایل‌های ایران‌یکان از دارایی محلی ارائه‌شدهٔ کاربر آمده‌اند؛ سند خرید یا شرایط مجوز همراه این تغییر ایجاد یا تأیید نشده است.
