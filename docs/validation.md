# گزارش بررسی نسخهٔ آزمایشی

تاریخ: ۲۰۲۶-۱۰-۰۱. PHP 8.2.12، MariaDB محلی جدا روی پورت 3317، Chrome بدون نمایش پنجره. هیچ حساب واقعی پیامک یا پرداخت استفاده نشده است.

| بررسی اجراشده | نتیجه |
|---|---|
| ۴۸ حالت صفحات عمومی؛ عرض ۳۲۰، ۳۹۰، ۷۶۸، ۱۴۴۰ در روشن/تیره | بدون سرریز، خطای صفحه یا اسکریپت |
| ۷۲ حالت صفحات پنل، همین عرض‌ها و حالت‌ها | بدون سرریز یا خطا؛ کنترل نقش‌ها و حفظ فرم صف نیز گذشت |
| ۲۴ حالت اجزای خدمات، منو و مدیریت خدمات | بدون سرریز؛ انتخاب و جست‌وجو هماهنگ |
| ۱۳ بررسی هسته | انتشار، فیلتر، مدت واقعی، رزرو و پرداخت تکراری، جداسازی سالن و نظر مراجعه |
| درخواست هم‌زمان برای یک ظرفیت | یک رزرو ثبت شد، درخواست دیگر رد شد |
| پرداخت با درگاه آزمایشی داخلی | تلاش قبلی استفاده شد، پاسخ مبهم پرداخت ثبت نکرد، پاسخ تأیید تکراری فقط یک رسید داشت |
| ۱۳ بررسی مسیر مرورگر | رزرو تا کارت نوبت، بارگیری مجدد، QR، رد فایل نامعتبر، تصویر معتبر، انتشار، علاقه‌مندی، فاصله و نقشه اختیاری، قطع ارتباط |
| ۱۶ بررسی صف و OTP | گردش صندلی، پایان تکراری، غیبت تکراری، دسترسی سالن، کد صحیح/غلط/منقضی/مصرف‌شده و تلاش دوباره بعد از پیامک ناموفق |
| PWA | حذف کش قبلی رشن و حفظ کش برنامهٔ دیگر؛ صفحهٔ عمومی آفلاین بدون کش صفحهٔ خصوصی |
| مهاجرت و بازیابی | نصب ۲۱ مهاجرت، ارتقای ۱۸ به ۲۱ با حفظ رنگ سالن، اجرای دوباره بدون تغییر، بازیابی سالن/نوبت/پرداخت/دفتر مهاجرت |
| preflight | وابستگی‌ها، پوشه‌های نوشتنی و دیتابیس آزمایشی آماده |

فایل‌های PHP نسخه بررسی نحوی شده‌اند. ایراد سرریز ۳۲۰ پیکسل و مسیریابی QR محلی در جریان بررسی رفع و دوباره بررسی شدند.

این گزارش تضمین همهٔ حالت‌های ممکن نیست. آزمون تحویل واقعی پیامک، درگاه واقعی، نسخهٔ نصب‌شده روی گوشی واقعی، تنظیمات Apache/cPanel و بار هم‌زمان زیاد هنوز به محیط مقصد نیاز دارد. بازبینی انسانی صفحه‌خوان، همهٔ برنامه‌های کاری/مرخصی سالن و گردش عملی روز کاری هم قبل از انتشار انجام شود. تست‌های مرورگر با سرویس نقشهٔ جایگزین اجرا شدند و دسترسی زندهٔ OpenStreetMap تأیید نشده است.
