# رشن — نوبت‌دهی و مدیریت سالن

سامانهٔ نوبت‌دهی و مدیریت برای **آرایشگاه‌های مردانه** و **سالن‌های زیبایی
بانوان** (و سالن‌های مختلط). PHP ساده بدون فریم‌ورک، قابل نصب روی هاست
اشتراکی cPanel.

## برای چه کسانی

| کاربر | کارهایی که انجام می‌دهد |
|---|---|
| مشتری | کشف سالن بر اساس شهر، خدمت، قیمت و امتیاز؛ رزرو آنلاین «اول زمان» یا «اول خدمت»؛ رزرو چند خدمت با چند متخصص در یک مراجعه؛ کارت نوبت، افزودن به تقویم، لغو در مهلت؛ «نوبت‌های من»، علاقه‌مندی و نظر |
| صاحب سالن / مدیر | صف امروز، رزروها، مشتریان (با یادداشت رنگ مو، نوع پوست، حساسیت‌ها)، خدمات و دسته‌ها با قیمت «ثابت» یا «از»، مهارت و قیمت اختصاصی هر نفر، ساعت کاری و مرخصی، قوانین رزرو (افق، حداقل فاصله، مهلت لغو، تعطیلات رسمی، بیعانه)، گزارش روزانه و ماهانه، صفحهٔ عمومی، QR، پیامک |
| پذیرش | پذیرش حضوری، ثبت رزرو تلفنی، تأیید بیعانه، تسویه با تخفیف و انعام |
| آرایشگر / متخصص | صف و نوبت‌های خودش، شروع و پایان خدمت، فروش خودش |
| مدیر پلتفرم | فهرست سالن‌ها، فعال/غیرفعال‌سازی، ورود پشتیبانی ثبت‌شده، بررسی انتشار و نظرها، تعطیلات رسمی |

## انتشار نسخهٔ تازه

`VERSION` و `CHANGELOG.md` را به‌روز کنید و تگ `vX.Y.Z` را push کنید؛ GitHub
Action آزمون می‌گیرد، بسته را می‌سازد و Release را منتشر می‌کند، و هاست‌ها
خودشان به‌روز می‌شوند. جزئیات: [docs/updates.md](docs/updates.md).

## ساختار

```text
app/Core          مسیریاب، نشست، احراز هویت، دیتابیس، مهاجرت، کرون
app/Domain        منطق کسب‌وکار: Booking، Catalog، Queue، Payment، Salon، Staff، Customer، Messaging
app/Http          کنترلرها و middlewareها
app/Support       کمک‌تابع‌ها، تاریخ شمسی، نوع سالن (Audience)، تم‌ها
resources/views   نماها؛ components و layouts مشترک
public/assets     reshen.css (سیستم طراحی)، app.js، فونت‌ها و آیکون‌ها
database          مهاجرت‌های نسخه‌دار
tools             مهاجرت، پیش‌بررسی، آزمون جریان‌ها، دادهٔ نمونه
docs              طراحی، معماری، نصب و ارتقا
```

## راه‌اندازی برای توسعه

```text
cp .env.example .env              # اتصال دیتابیس را تنظیم کنید
composer install
php tools/migrate.php
php tools/seed-demo.php           # دو سالن نمونه و کاربران هر نقش
php tools/seed-demo-history.php   # سابقهٔ ۴۵ روزه برای گزارش‌ها
php -S 127.0.0.1:8080 -t public public/index.php
php tools/login-link.php 09120000001   # لینک ورود صاحب سالن نمونه
```

کاربران نمونه: `09120000001` صاحب هر دو سالن، `09120000002` پذیرش سالن
بانوان، `09120000003` آرایشگر، `09120000009` مدیر پلتفرم. با
`SMS_DRIVER=log` کدهای ورود در `storage/logs/sms.log` نوشته می‌شوند.

## آزمون

```text
php tools/test-flows.php          # ۷۴ آزمون (داخل تراکنش؛ چیزی ذخیره نمی‌شود)
node tools/check-contrast.mjs     # کنتراست همهٔ تم‌ها در حالت روشن و تیره
php tools/check-inline-styles.php # نگهبان سیستم طراحی
cd tests/ui && npm ci && npx playwright test   # دسترس‌پذیری، چیدمان، تصویری
```

گالری زندهٔ اجزا: `/system/design` (پنل پلتفرم).
